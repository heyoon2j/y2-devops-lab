# 업무일지를 진행 현황에 반영

1. 대상 프로젝트의 AGENTS.md, LOG.md, STATUS.md를 읽습니다. 날짜가 지정되면 해당 항목을 사용하고, 생략하면 Asia/Seoul 기준 오늘 항목을 사용합니다. 해당 일지가 없으면 변경 없이 알려줍니다.
2. 일지의 작업 결과와 STATUS의 작업 ID를 대조합니다. 기록의 결과와 근거가 해당 작업의 완료 조건을 충족하면 완료로 갱신하고 `[업무일지](LOG.md#YYYY-MM-DD)`를 근거에 추가합니다. 기존의 관련 근거는 보존합니다. 명시적으로 확인된 착수와 차단도 해당 상태에 반영할 수 있습니다.
3. 작업 ID가 불명확하거나 완료를 확인할 근거가 부족하면 상태를 유지하고 STATUS의 확인할 사항에 근거 링크와 함께 남깁니다. 이미 완료·제외됐거나 이후 기록이 반영된 작업은 이전 일지만으로 되돌리지 않습니다. 같은 확인 사항과 근거 링크는 중복 추가하지 않습니다.
4. 후속 행동이 일지에 명시돼 있고 현재 남은 작업과 일치하면 STATUS 요약의 다음 행동을 갱신합니다. STATUS 작업 표가 바뀌면 프로젝트 루트에서 `python3 .agents/scripts/update_progress.py`를 실행합니다. 파일이 없는 기존 프로젝트에서는 STATUS의 집계 기준을 따릅니다.
5. 갱신한 작업, 진행률 변화, 남은 확인 사항을 알려줍니다. 일지 원문을 유지하고 같은 입력을 다시 반영했을 때 같은 상태나 근거를 중복 기입하지 않습니다.
