# 개발 에이전트 골격 설계

여러 언어와 환경에서 재사용할 개발 에이전트의 설계 초안입니다.
첫 적용 대상은 형제 디렉터리의 `infra-terraform`이며, 현재 범위는 설계 문서 작성입니다.
구현 언어, 모델, 프레임워크와 벡터 DB는 아직 확정하지 않았습니다.

핵심 구조는 **공통 실행 흐름 + 프로젝트별 프로필 + 교체 가능한 어댑터**입니다.
Terraform의 규칙을 공통 코어에 넣지 않고 프로젝트별 설정과 정책으로 분리합니다.

| 문서 | 내용 |
| --- | --- |
| [아키텍처](docs/ARCHITECTURE.md) | 구성 요소, 처리 흐름, 하네스와 RAG 확장 방식 |
| [프로젝트 프로필](docs/PROJECT_PROFILES.md) | 프로필 계약, Terraform 적용안, 다른 언어로 확장 |
| [평가 계획](docs/EVALUATION.md) | 완료 기준과 초기 평가 시나리오 |
| [실행 정책](policy/README.md) | 후속 실행기가 구현할 권한과 실행 경계 |

다음 설계 결정은 첫 작업의 요구사항과 완료 기준입니다. security-group 공통 모듈을
첫 사례로 삼아 설계와 검증 계획을 확정한 뒤, 실행 언어와 모델 연결 방식을 선택합니다.
