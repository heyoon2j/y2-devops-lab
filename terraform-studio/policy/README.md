# 실행 정책 계약

현재는 설계 문서 단계입니다. 아래는 후속 실행기가 구현해야 할 계약입니다.

- 읽기: 프로젝트의 허용 파일만 읽고 숨김 경로, 비밀값, state 및 외부 링크를 제외합니다.
- 쓰기: 작업별 격리 checkout에서 허용한 경로만 수정합니다. 경로 탈출과 링크를 검사합니다.
- 명령: 프로필 선언만으로 실행을 허용하지 않습니다. 실행기가 argv, cwd, 도구,
  네트워크 접근과 자격 증명 요구사항을 검사해야 합니다.
- 검증: 로컬 형식·테스트 검사와 provider 설치·클라우드 접근을 구분합니다.
- 배포: plan/apply/destroy, state 조작 및 backend 변경 실행에는 별도 명시적 승인이 필요합니다.
- 종료: 반복 횟수, 시간 또는 토큰 한도에 도달하면 현재 diff와 실패 원인을 남깁니다.

일반 소스 내부에도 비밀값이 있을 수 있으므로 LLM 또는 인덱스 서비스 연결 전에
입력 검사와 외부 전송 정책을 구현합니다. 문서의 규칙 자체가 실행을 통제하지는 않습니다.
