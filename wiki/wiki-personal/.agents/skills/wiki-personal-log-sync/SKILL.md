# 개인 업무일지 반영

1. 대상 폴더의 AGENTS.md, RESPONSIBILITIES.md, STATUS.md, LOG.md를 읽습니다. 요청한 날짜 항목을 사용하고, 생략하면 Asia/Seoul 기준 오늘 항목을 사용합니다. 해당 항목이 없으면 그대로 두고 알려줍니다.
2. 일지에 적힌 업무 ID를 책임 목록과 대조합니다. 해당 회차의 완료 기준과 근거가 확인되면 마지막 완료일과 일지 링크를 갱신합니다. 일정이나 조건이 확정돼 있으면 다음 실행을 표시하고 완료한 회차는 대기로 전환합니다. 착수나 차단이 명시된 다음 회차가 있다면 그 상태를 반영합니다.
3. 다음 행동이나 실행일을 확인할 수 있으면 반영합니다. 일지나 업무 정의에서 알 수 없는 내용은 추정하지 않습니다. 기존 다음 실행이 완료된 회차의 일정이라면 제거하고, 새 일정이 확인되지 않으면 미정으로 적습니다.
4. 업무 ID나 기록이 모호하면 기존 상태를 유지하고 확인할 사항에 업무 ID와 일지 링크를 적습니다. 이전 일지를 다시 읽을 때 이후에 확인된 운용 상태나 마지막 완료일을 되돌리지 않습니다.
5. 같은 날짜와 근거를 다시 처리할 때는 중복된 링크나 확인 사항을 추가하지 않습니다. 일지와 책임 정의는 보존하고, STATUS의 변경과 남은 확인 사항을 요약합니다.
