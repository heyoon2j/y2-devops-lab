# 개인업무 위키

내가 맡은 프로젝트 작업과 반복 점검, 일회성 요청, 아직 검토할 할 일을 한곳에서 봅니다.

| 할 일 | 기록하는 곳 | 예시 |
| --- | --- | --- |
| 프로젝트 작업 | STATUS의 프로젝트 업무에 원래 작업 링크와 내 다음 행동 | CSV 프로젝트 T2의 테스트 결과 확인 |
| 일회성 업무 | STATUS의 일회성 업무에 ID와 완료 기준 | A1 · 온보딩 안내 링크 수정 |
| 반복 업무 | RESPONSIBILITIES에 실행 조건, STATUS에 현재 회차 | R1 · 매주 CI 실패 추세 점검 |
| 아직 정리하지 않은 일 | STATUS의 정리할 할 일 | 배포 알림 개선을 프로젝트 작업으로 등록할지 확인 |

정리할 할 일은 다음 행동이 정해지면 해당 목록으로 옮깁니다. 이번에 우선할 일은 STATUS 상단에 기존 항목을 참조해 적습니다.

## 시작하기

1. 반복 업무는 [RESPONSIBILITIES.md](RESPONSIBILITIES.md)에 범위, 실행 시점과 완료 기준을 적습니다.
2. [STATUS.md](STATUS.md)에 같은 업무 ID로 행을 추가하고, 아직 실행한 적이 없으면 마지막 완료일과 근거에 `—`를 적습니다.
3. 실행하거나 차단된 일이 생기면 [LOG.md](LOG.md)에 기록합니다.
4. Codex에서 이 폴더를 열고 `$wiki-personal-log-sync로 오늘 업무일지를 상태에 반영해줘.`라고 요청합니다. 날짜를 지정해 특정 일지를 반영할 수도 있습니다. [스킬 지침](.agents/skills/wiki-personal-log-sync/SKILL.md)

## 일정 관리

[STATUS.md의 날짜와 시간](STATUS.md#날짜와-시간)에 따라 마감, 실행 일정, 프로젝트 확인 시점을 기록합니다. 캘린더 일정이 생기면 연결할 수 있습니다.
